# paddle-lottery-experiment

A PaddlePaddle-based experimental project for China Sports Lottery Super Lotto / 大乐透 data modeling.

> This project is for educational and experimental purposes only. Lottery results are random; this project does **not** guarantee prediction accuracy.

## Project Overview

This repository explores lottery data processing, model training, and inference using PaddlePaddle.

The project includes:

- Historical Super Lotto data collection
- Data cleaning into model-ready format
- PaddlePaddle neural network training
- Early stopping and best-model saving
- Experimental lottery number generation
